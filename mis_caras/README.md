# Tus caras

Aquí van **tus fotos recortadas (PNG con fondo transparente)** para las miniaturas, carruseles y posts.
Las subes desde el panel (**Tu canal → Tus caras**) y se guardan con el nombre del gesto y la dirección de la mirada,
por ejemplo `cara feliz mirando hacia la izquierda.png`. Gestos: feliz, sorpresa, pensando, decepción, asco, triste, what.
Esta carpeta NUNCA se sube a GitHub (son fotos tuyas).
