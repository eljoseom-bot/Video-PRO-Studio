# Tu música de fondo (opcional)

Pon aquí canciones suaves para el fondo de tus vídeos (.mp3 o .wav): por ejemplo de la Biblioteca de audio de YouTube
(Studio → Biblioteca de audio), que no exige atribución en las pistas marcadas así.
El programa elige solo las canciones **estables** (sin "drops") y las encadena en orden distinto en cada vídeo.
Esta carpeta NUNCA se sube a GitHub. Si está vacía, usa música libre de Openverse.
